# inria_academy — Agent Instructions

## Setup

```bash
uv sync          # creates .venv, installs from pyproject.toml + uv.lock
```

Python ≥ 3.11 required. No `__main__.py` exists — scripts run directly:

```bash
uv run python src/1.Reminder_Fourier/spectral_filtering_demo.py
```

## Running

Each script under `src/` is self-contained. Run with:

```bash
uv run python src/X.Topic/script.py
```

Scripts generate PNG figures (saved alongside the script). These are gitignored (`*.png`, `outputs/`).

## Structure

7 numbered topic directories under `src/`, each containing standalone demo scripts:

| Dir | Topic |
|---|---|
| `1.Reminder_Fourier` | Fourier basics, spectral filtering |
| `2.Reminder_Wavelets` | CWT, wavelet bases, time-frequency tiling, denoising |
| `3.STFT_WVD_SPWVD` | STFT, Wigner-Ville, Smooth Wigner-Ville |
| `4.EMD_EEMD_CEEMDAN` | EMD, EEMD, CEEMDAN, mode mixing |
| `5.SWT` | Stationary Wavelet Transform + EMD hybrids |
| `6.VMD` | Variational Mode Decomposition |
| `7.MVMD` | Multivariate VMD (includes `mvmd.py` library) |

Only two files are reusable library modules; everything else is a script:
- `src/7.MVMD/mvmd.py` — Multivariate VMD implementation
- `src/5.SWT/swt_emd_helpers.py` — SWT + EMD utility functions

## Dev commands

```bash
uv run ruff check src/    # lint (no ruff.toml config — uses defaults)
uv run mkdocs serve        # preview docs (gallery is auto-generated)
uv run bash docs/_scripts/build_api.sh        # regenerate API docs
```

No tests, no typechecking. CI runs ruff lint on push to main.

## Documentation

The site lives in `docs/` with mkdocs-material. Gallery images are generated at build time
by `docs/_scripts/build_gallery.py` (best-effort, no caching). API docs are generated by
`docs/_scripts/build_api.sh` using pdoc.

Generated files are gitignored: `docs/gallery/_build/`, `docs/reference/`, `site/`.

GitHub Pages deployment is configured via `.github/workflows/docs.yml`.

## Gotchas

- **License conflict**: `LICENSE` says BSD 2-Clause; `README.md` says CC BY-NC-ND 4.0. Verify which applies.
- `uv run python -m` (per README) does not work — there is no `__main__.py`.
- `pyproject.toml` declares `mkdocs-material` in both `[project.optional-dependencies]` and `[dependency-groups]`.
- All scripts use `np.random.seed()` for reproducibility.
- `mkdocs-gallery` excludes library modules (`mvmd.py`, `swt_emd_helpers.py`) from the gallery via `ignore_pattern`.
